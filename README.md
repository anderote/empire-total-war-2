# Empire Total War 2 — code-only snapshot

This public repository contains C# gameplay and Unity editor source, authoring and verification tools, package manifests, and the Unity editor version used by the project.

It intentionally excludes game assets and runtime content, including scenes, meshes, textures, animation data, audio, and generated data. The source references content from the full local project, so this snapshot is not a complete playable Unity checkout.

No license has been added. Public visibility does not grant permission to reuse the code.
